## 2. 🎯 Problem Statement & Our Solution

### ⚠️ The Challenge (SIH Problem Statement ID: SIH-1608 / Smart Maritime)
India commands a **7,516 km coastline** with over **4 million active artisanal and mechanized fishermen**. Every monsoon and cyclone season, thousands of seafaring lives are put in mortal jeopardy due to:
1. **Siloed, Inscrutable Data**: Ocean advisories from INCOIS, wave models from NIOT, and Doppler alerts from IMD are published across disparate scientific portals in complex units (m/s, PSU, millibars) that artisanal seafarers cannot easily decode at 03:00 AM before departure.
2. **The "Opportunity Trap"**: Existing commercial apps promote Potential Fishing Zones (PFZ) without strict hazard synchronization. Vessels often steer directly into deadly coastal squalls and high swell periods chasing pelagic fish schools.
3. **Severe Language & Literacy Barriers**: Over 70% of coastal fishermen rely exclusively on vernacular coastal dialects (Kannada, Malayalam, Tamil, Telugu, Odia, Gujarati, Marathi, Bengali) and require zero-latency speech broadcasts rather than textual dashboards.
4. **Lack of Distress Telemetry & Verification**: In emergencies, boats struggle to broadcast formatted coordinates and vessel seaworthiness credentials to the nearest Indian Coast Guard MRCC (Maritime Rescue Coordination Centre).

### 💡 Our Solution: SAGAR-SAFE AI
**SAGAR-SAFE AI** is a next-generation **Ocean Glass Command Center** powered by an autonomous **5-Agent Decision Pipeline**:
- 🛡️ **Autonomous Safety Arbiter**: Instantly reconciles satellite chlorophyll and thermal upwelling against real-time significant wave height, wind shear, and swell periods with a hard **"Safety Overrides Opportunity"** priority rule.
- 🗣️ **10 Coastal Dialects & Voice Briefings**: Zero-latency Speech Synthesis (TTS) broadcasting marine weather and go/no-go advisories in 10 coastal languages: *English, Hindi, Kannada, Malayalam, Tamil, Telugu, Marathi, Bengali, Odia, and Gujarati*.
- 📍 **Digital Twin GIS Map & 100+ Ports Directory**: Interactive vector current flows, bathymetry layers, PFZ hotspots, danger polygon overlays, and an exhaustive database of all major, non-major, intermediate, and landing harbours across maritime India.
- 🚨 **One-Touch Maritime Distress (SOS) Beacon**: Synthesizes Vessel Registration, GPS Coordinates, emergency type (Capsize, Fire, Engine Failure, Medical), and automated Coast Guard channel dispatch scripts.

## 3. ✨ Key Features

### 🤖 Multi-Agent Decision Engine
- 🟢 **Composite Verdict HUD**: Provides an instantaneous `SAFE (OPTIMAL)`, `CAUTION (MARGINAL)`, or `UNSAFE (CRITICAL / STAY AT HARBOUR)` recommendation with transparent, explainable reasoning.
- ⚖️ **Craft-Specific Limit Re-evaluation**: Dynamically recalculates safety thresholds based on craft category:
  - *Traditional Vallam / Catamaran* (Max Wave: 1.5m | Wind: 25 km/h)
  - *Motorized Outboard Vessel* (Max Wave: 2.2m | Wind: 38 km/h)
  - *Mechanized Deep-Sea Trawler* (Max Wave: 3.5m | Wind: 52 km/h)

### 🌊 Oceanographic & Meteorological Ingestion
- 🛰️ **Thermal & Chlorophyll PFZ Analysis**: Ingests Sea Surface Temperature (SST) gradients ($\Delta SST \ge 0.5^\circ\text{C}/\text{km}$) and Chlorophyll-$a$ levels ($\ge 1.2\text{ mg/m}^3$) to pinpoint high-probability pelagic zones (Tuna, Mackerel, Pomfret).
- 💨 **Atmospheric Barometer & Squall Warnings**: Real-time monitoring of barometric drops, gale warnings, Beaufort numbers, and gust velocities.

### 🌐 10-Language Coastal Localization & Voice Assistant
- 🎧 **Audio Marine Briefings**: One-click voice broadcasts delivering spoken advisories in fisherman-friendly vernacular language.
- 🔄 **Cross-Tab & Localized Persistence**: Instant synchronization of language preferences across desktop navigation, mobile bottom bars, and settings.

### ⚓ National Maritime Harbours & Ports Registry
- 🗺️ **100+ Catalogued Ports**: All 13 Major MoPSW Ports, State Maritime Board commercial ports (Gujarat GMB, Maharashtra MMB, Kerala, Tamil Nadu, Andhra Pradesh, Odisha), and prime fishing landing centers.
- 📊 **Detailed Port Telemetry**: Deep inspection modal displaying channel draft depth, berths, exim capacity, target marine species, and Coast Guard station coordinates.

### 🚨 Maritime Distress (SOS) & Safety Beacon
- 📡 **Emergency Broadcast Generator**: One-click generation of formatted emergency payloads with vessel registration, live GPS coordinates, and distress nature.
- 📻 **VHF Marine Channel 16 Directives**: Instant visual and audio scripts for ship-to-shore emergency distress relay.

### 🌿 Ambient Marine Eco-Layer & Ocean Glass UI
- 🐠 **Native Indian Marine Fauna**: GPU-composited CSS3 keyframe animations of Giant Manta Rays, Indian Mackerels, Skipjack Tunas, and Olive Ridley Turtles with scientific eco-sonar cards.
- 💎 **Ocean Glassmorphism**: Aerospace-grade frosted glass depth (`backdrop-filter: blur(28px)`), top-edge rim lighting, and responsive dark-mode command visuals.

## 5. 🛠️ Installation & Setup Guide

Follow these steps to spin up the development environment locally on your workstation:

### Prerequisites
- **Node.js**: `v18.0.0` or higher ([Download Node.js](https://nodejs.org/))
- **npm**: `v9.0.0` or higher (bundled with Node) or **yarn** / **pnpm**
- **Git**: Modern Git CLI installed

### Step-by-Step Terminal Setup

```bash
# 1. Clone the repository
git clone https://github.com/your-team-username/sagar-safe-ai.git

# 2. Navigate into the project directory
cd sagar-safe-ai

# 3. Install dependencies
npm install

# 4. (Optional) Set up your environment variables
cp .env.example .env

# 5. Start the local development server
npm run dev
```

The application dev server will boot up at:
```
👉 http://localhost:3000
```

### Useful Commands

| Command | Action |
| :--- | :--- |
| `npm run dev` | Starts development server on port 3000 with live reload |
| `npm run build` | Compiles TypeScript and builds production assets to `dist/` |
| `npm run lint` | Executes type checks and ESLint verification |
| `npm run preview` | Locally previews the production build from `dist/` |
